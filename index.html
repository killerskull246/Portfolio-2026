    • CRUD Application: For this activity aims to create a web-based CRUD application using HTML, CSS, JavaScript, and PHP. The application will manage a list of items stored in a MySQL database hosted on a XAMPP server. The project involves setting up the project structure with necessary files (index.php, style.css, script.js, database.php), creating the MySQL database "crud_db" and a table "items" with specified columns, designing a user interface (UI) using HTML and PHP with input fields, buttons, and a data display table, styling the application using CSS, and finally implementing CRUD (Create, Read, Update, Delete) operations using PHP and JavaScript to manage database items.

    E-Commerce Platform: This activity aims to develop a simple e-commerce product catalog featuring a shopping cart, user roles (Seller and Customer), item tracking, a checkout system, and product management (Add, Update, Delete) for sellers. The backend will use PHP, while JavaScript will handle interactivity and CSS will provide styling. The project requires a web server (XAMPP, WAMP, or LAMP), basic PHP knowledge, a MySQL database, and JavaScript & CSS for the frontend.

    Vaccine Inventory System: This activity develops a simple vaccine inventory system using PHP (backend), MySQL (via XAMPP), and JavaScript (user interface and validation). The system implements core CRUD (Create, Read, Update, Delete) functionality for managing vaccine records, enabling users to track inventory, adjust stock levels, and manage entries. Client-side validation ensures data accuracy, while secure server-side communication with the database is handled by PHP. This project provides practical experience with CRUD database operations and JavaScript's role in enhancing user interaction. Required tools include XAMPP (Apache and MySQL), a text editor (VS Code, Sublime, or Notepad++), and a web browser.

    Bank Transaction System: This activity develops a simplified bank transaction system using PHP, JavaScript, and MySQL (XAMPP). It involves creating a bank_db database with a transactions table, implementing PHP functions for deposits, withdrawals, and balance checks, and building an HTML, JavaScript, and AJAX-based frontend. The system allows users to manage accounts using account numbers and amounts. The focus is on practical implementation and deployment on a local server.

    JavaScript CRUD System: This activity details building a JavaScript CRUD application with login, registration, and image upload, using LocalStorage for data persistence. It involves creating HTML files for registration, login, and a dashboard with CRUD operations and image previews. JavaScript handles DOM manipulation, event listeners, and data storage. Deployment uses XAMPP, requiring proficiency in JavaScript fundamentals, DOM manipulation, event handling, and LocalStorage. The grading rubric covers file structure, successful registration/login, functional CRUD operations, image uploads/previews, and clean code.

    Dynamic CRUD: For this last activity guides a creating of a dynamic CRUD web application using XAMPP, PHP, MySQL, JavaScript, jQuery, JSON, and Bootstrap. It involves setting up a dynamic_crud database with a users table, creating PHP files for database interactions (fetching, inserting, updating, and deleting data), and developing a Bootstrap and jQuery-based frontend for AJAX requests and responsive table display. The application provides dynamic add, edit, and delete functionality without page reloads. Submission requires all PHP files, a database SQL export, screenshots/screen recordings of CRUD operations, and a README file.
